# 分镜技能包 · 使用说明

包里有两个技能（均已发布到扣子平台，这里是本地完整副本，离线也能用）：

| 文件夹 | 是什么 | 怎么用最快 |
|---|---|---|
| 镜头配方与分镜生成 | 157个电影级镜头配方 + 211套风格 + Ink Press 36.2s 模板，一条流水线：需求 → 分镜JSON → Remotion 可渲染工程 | **双击「一键运行.command」** |
| 分镜提示词和视频提示词 | 给 AI 生视频（即梦/可灵）写分镜提示词的万能公式 + 要素库 | 打开 `分镜提示词和视频提示词/references/fenjing-prompt-lib.md` 照着写 |

---

## 一、最快用法：双击「一键运行.command」

自动跑完「分镜编排 → 生成 Remotion 工程」，输出在 `remotion_output/`。

想换需求：打开「示例_生成分镜.py」，改 `user_prompt` 和 `total_duration`，再双击一键运行。

## 二、写代码调用（三层接口）

```python
import sys; sys.path.insert(0, "镜头配方与分镜生成/scripts")
from library import ShotRecipeLibrary
from shot_agent import ShotAgentReasoner
from remotion_generator import RemotionCodeGenerator

lib = ShotRecipeLibrary(auto_populate=False)     # 技能1：配方库
lib.searchShots(tags=["transitions"])           # 按标签找配方
lib.getShotById("whip-pan")                     # 单张配方卡
lib.listAllStyles()                             # 211套风格
lib.getTemplate("inkpress_promo_36.2s")         # 成品模板

agent = ShotAgentReasoner(lib)
sb = agent.build_storyboard(                     # 技能2：分镜编排
    user_prompt="你的需求文案",
    total_duration=36.2,                        # 总时长（秒）
    asset_list=["./assets/1.png"],               # 素材（可选）
    beat_points=[0, 2.4, 5.0],                   # 节拍点（可选）
    template_id="inkpress_promo_36.2s",          # 模板模式（可选，删掉=自动编排）
    style_id="inkpress-dark",
)

gen = RemotionCodeGenerator(lib)
gen.generate(sb, output_dir="remotion_output")  # 技能3：出 Remotion 工程
```

生成后渲染视频（电脑已有 node v22）：

```bash
cd remotion_output
npm install && npm run dev    # Remotion Studio 预览
npm run render                # 出片 MP4
```

> 注意：工程是代码骨架，各镜头组件（shotRecipes.tsx）按配方卡里的 `implementationNotes` 实现，可从 video-shotcraft 官方 demo 移植。

## 四、分镜提示词技能（知识型）

万能公式：**景别 + 镜头运动 + 画面内容 + 场景光线 + 画面风格 + 时长**

完整公式讲解、五类要素库、22 条运镜写法、实操示例，全在：
`分镜提示词和视频提示词/references/fenjing-prompt-lib.md`

照着填空写出来的提示词，即梦/可灵/海螺都能识别，画面连贯、角色统一。
